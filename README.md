# Freelancer Portfolio

A professional portfolio website designed for a Freelance Tech Solutions Architect. It highlights various services, including App Development, Full Stack Development, CRM Management, UI/UX Design, and Resume Writing.

## Features
- **Responsive Design**: Adapts beautifully to mobile, tablet, and desktop screens.
- **3D Interactive Animations**: Powered by Vanilla-tilt.js, providing an engaging parallax effect on service and project cards.
- **Modern UI**: Clean layout with a dark theme, glassmorphism, and neon accents.
- **Contact Integration**: Uses Formspree for easy contact form submissions.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Vanilla-tilt.js (for 3D animations)
- Particles.js (for background effects)

## Local Development
1. Clone this repository.
2. Open `index.html` in your web browser.
3. No build steps are required.

## Deployment
This project is ready to be deployed on platforms like Vercel, Netlify, or GitHub Pages. Just link the repository and deploy the root directory.
